# 🧼 Ultrawashtex - Premium Laundry Service

**Ultrawashtex** is Andhra Pradesh's largest launderette service provider platform. The application provides customers with seamless access to professional laundry care, dry cleaning, express 24-hour turnaround, corporate bulk laundry solutions, and local pickup point locators.

---

## ✨ Features

- **Service Showcase:** Detailed information on Dry Cleaning, Doorstep Pickup & Delivery, Corporate Laundry, and Express 24h Services.
- **Pickup Point Locator:** Helps users locate nearest service hubs (50+ points available).
- **Process Workflow:** Clear 4-step interactive breakdown (Pick up & Sort → Wash & Dry → Fold & Iron → Pack & Deliver).
- **Corporate Solutions:** Volume discount requests and bulk laundry booking for hotels, hospitals, and offices.
- **Responsive Design:** Optimized for mobile, tablet, and desktop browsing.

---

## 🛠️ Tech Stack

- **Framework:** Next.js / React
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
